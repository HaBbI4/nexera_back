# Контент: что заполнено макетом и что заменить

Сайт наполнен маркетинговым контентом для демонстрации. Ниже — статус по блокам.

## Заполнено (можно править в коде)

| Блок | Источник | Статус |
|---|---|---|
| Услуги (9 шт.) + детальные страницы | `web/src/content/services.ts` | Готовый копирайт Nexera; цены не указаны |
| Позиционирование, преимущества, о студии | `web/src/content/positioning.ts` | Готово |
| Процесс | `web/src/content/process.ts` | Готово |
| FAQ | `positioning.ts` → `fallbackFaq` (если API FAQ пуст) | Готово; позже можно перенести в админку |
| Бриф: типы, подсказки, бюджет | `web/src/content/brief.ts` | Бюджеты **редактируемые**, помечены как не-оферта |
| Демо-кейсы (6) | `web/src/content/cases.ts`, флаг `demo: true` | Концепты + бейдж «Концепт»; цели, не метрики |

## Макеты / заглушки — заменить до production

1. **Контакты** — `web/src/content/contacts.ts`, все с `isMock: true`:
   - email `hello@example.com`
   - phone `+7 (000) 000-00-00`
   - Telegram `@your_studio`
   - город «Москва» (без улицы)
   - VK → `#` (скрыт в UI / не в schema)
   - Показываются в футере и `/contact` с пометкой mock.
   - **JSON-LD** намеренно **не** включает `isMock`-поля (`getStructuredDataContacts`).
   - Альтернатива: опубликовать реальные через API `contact_info` и переключить футер/контакт на API.

2. **Юрлицо** — `legalEntityPlaceholder = "ООО «Название»"` в contacts + footer/privacy. Заменить реквизитами.

3. **Политика ПДн** — `/privacy` остаётся черновиком до юридической редакции (ИНН, адрес оператора, сроки хранения).

4. **Демо-кейсы** — удалить или выставить `demo: false` и заменить тексты/визуалы реальными проектами. Функция `getRealCasesOnly()` уже фильтрует `demo`.

5. **Диапазоны бюджета** в брифе — подтвердить бизнес-моделью; файл помечен как editable config.

6. **Отзывы / метрики / команда / адрес офиса** — не выдуманы; блок отзывов на главной только если API вернул approved.

7. **Домен** — `NEXT_PUBLIC_SITE_URL`.

8. **Баннеры** из API — опционально.

## Не копировать с web-valley.ru

Чужие кейсы, телефоны, email, метрики, цены «от», отзывы и соцсети другой студии **запрещены**. Референс использован только для структуры услуг/FAQ/аргументации.

## Техзависимости

- Backend + Postgres/Redis для живых форм.
- `web/next.config.ts` проксирует `/api` и `/media`.
